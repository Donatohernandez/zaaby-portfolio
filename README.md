# Zaaby – AI-Powered iOS Productivity App

## Overview

Zaaby is an intelligent productivity application that transforms saved content into actionable insights. Built for users who constantly save articles, videos, and links but struggle to extract value from them, Zaaby uses AI to automatically process, organize, and turn saved content into meaningful tasks and insights.

**Live:** [zaaby.app](https://zaaby.app/)

## Key Features

**AI-Powered Link Processing**
- Intelligent content extraction from links, articles, and saved content
- Automatic categorization and tagging based on content type

**Automatic Task Generation**
- AI analyzes content and suggests actionable tasks
- Tasks flow through customizable status pipeline
- Smart reminders and priority management

**Smart Organization**
- Tag-based filtering and search
- Custom collections and folders
- Real-time sync across devices

**Subscription Management**
- Multiple tiers (monthly, quarterly, yearly)
- 7-day free trial
- RevenueCat integration for seamless payments

**User Onboarding**
- Guided setup flow
- Data integrity validation
- Tutorial system for feature discovery

## Tech Stack

**Frontend:**
- React Native + Expo SDK 54
- TypeScript
- React Hooks for state management

**Backend:**
- Supabase (PostgreSQL)
- Row-Level Security (RLS) for data protection
- Edge Functions for serverless logic

**AI & APIs:**
- OpenAI (gpt-4-mini)
- TikTok oEmbed API
- RevenueCat for in-app purchases

**Infrastructure:**
- EAS Build for iOS compilation
- Expo for rapid development and OTA updates
- TestFlight for beta distribution

**Security:**
- Comprehensive security audit implementation
- RLS-based access control
- Environment variable management
